# Ma'man · مأمن

Project page for **Ma'man**, a local-first tool that measures how easily people in a CSV dataset can be re-identified, even without names, and builds a safer copy for sharing.

Live: https://sulltanah.github.io/maman/

This repository contains only the static, bilingual (English / Arabic) landing page. The application's source code is private.

The interactive demo on the page is a replay of a real run of the local app on the public German Credit dataset (1,000 rows, public-release setting). The page never reads or uploads files.
